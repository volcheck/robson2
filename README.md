# Система учёта статистики родов по классификации Робсона

## Описание

Веб-приложение для ведения и обработки статистики по классификации Робсона в родильных отделениях.

## Стек технологий

- **Фронтенд**: React, TypeScript, Tailwind CSS, Vite
- **Бэкенд**: PHP 8.x, PDO
- **База данных**: MySQL 8.x
- **Сервер**: Apache2 (Ubuntu)

## Возможности

### Основной функционал
- ✅ Ведение записей о родах с полной информацией по классификации Робсона
- ✅ Учёт данных о новорождённых (многоплодная беременность)
- ✅ Дашборд с оперативной статистикой (сутки/неделя/месяц)
- ✅ Фильтрация и поиск записей
- ✅ Печать карточки родов
- ✅ Разграничение доступа по организациям

### Администрирование
- ✅ Управление организациями (суперадмин)
- ✅ Управление отделениями
- ✅ Управление врачами
- ✅ Управление пользователями и ролями
- ✅ Смена пароля

### Иерархия доступа

| Роль | Возможности |
|------|-------------|
| **Суперадминистратор** | Создаёт организации, назначает владельцев, просматривает записи и статистику всех организаций |
| **Владелец организации** | Создаёт отделения и врачей своей организации, вносит и редактирует данные, просматривает статистику, назначает наблюдателей |
| **Наблюдатель** | Просматривает записи и статистику своей организации (без возможности редактирования). Назначается владельцем |

## Установка

### 1. Требования

- Ubuntu 20.04+ 
- Apache 2.4+
- PHP 8.0+ (с расширениями: pdo_mysql, json, mbstring)
- MySQL 8.0+
- Node.js 18+ (для сборки фронтенда)

### 2. Установка зависимостей сервера

```bash
sudo apt update
sudo apt install apache2 php8.1 php8.1-mysql php8.1-mbstring php8.1-json mysql-server nodejs npm
sudo a2enmod rewrite
```

### 3. Создание базы данных

```bash
mysql -u root -p < backend/database/schema.sql
```

### 4. Настройка конфигурации БД

Отредактируйте `backend/api/config.php`:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'robson_stats');
define('DB_USER', 'ваш_пользователь');
define('DB_PASS', 'ваш_пароль');
```

### 5. Сборка фронтенда

```bash
npm install
npm run build
```

### 6. Развёртывание

```bash
# Создаём директорию
sudo mkdir -p /var/www/robson

# Копируем фронтенд
sudo cp -r dist/* /var/www/robson/

# Копируем API
sudo cp -r backend/api /var/www/robson/api

# Устанавливаем права
sudo chown -R www-data:www-data /var/www/robson
sudo chmod -R 755 /var/www/robson
```

### 7. Настройка Apache

```bash
sudo cp backend/apache/robson.conf /etc/apache2/sites-available/robson.conf
sudo a2ensite robson
sudo systemctl reload apache2
```

## Классификация Робсона (13 групп/подгрупп)

| Код группы | Описание |
|------------|----------|
| 1 | Nullipara, singleton, cephalic, ≥37 нед., спонтанные роды |
| 2a | Nullipara, singleton, cephalic, ≥37 нед., КС до начала родов |
| 2b | Nullipara, singleton, cephalic, ≥37 нед., КС после начала родов |
| 3 | Multipara (без КС в анамнезе), singleton, cephalic, ≥37 нед., спонтанные роды |
| 4a | Multipara (без КС в анамнезе), singleton, cephalic, ≥37 нед., КС до начала родов |
| 4b | Multipara (без КС в анамнезе), singleton, cephalic, ≥37 нед., КС после начала родов |
| 5.1 | Предыдущее КС, singleton, cephalic, ≥37 нед., спонтанные роды |
| 5.2 | Предыдущее КС, ≥37 нед., КС (до или после начала родов) |
| 6 | Все nulliparae с плодом в тазовом предлежании |
| 7 | Все multiparae с плодом в тазовом предлежании (вкл. с КС в анамнезе) |
| 8 | Все многоплодные беременности |
| 9 | Все аномалии предлежания (поперечное, косое) |
| 10 | Все одиночные беременности <37 недель с головным предлежанием |

## Предложенные улучшения

1. **Экспорт в Excel/CSV** — выгрузка данных для внешнего анализа
2. **Система отчётов** — формирование отчётов по группам Робсона с процентами
3. **Графики и диаграммы** — визуализация динамики показателей
4. **Автоматическое определение группы Робсона** — по введённым данным
5. **Аудит действий** — журнал изменений записей
6. **Уведомления** — при приближении сроков
7. **Резервное копирование** — автоматический бэкап БД
8. **Мобильная адаптация** — работа на планшетах в отделениях
9. **Интеграция с МИС** — импорт данных из медицинских информационных систем
